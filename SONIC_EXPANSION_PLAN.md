## EXPANSION RULES & GUIDELINES

### Rule 1: Parameter Uniqueness
**Every new audio parameter must map to either:**
- A) An unused visual parameter
- B) A new visual parameter dimension
- C) A temporal modulation of an existing visual parameter

**Example:**
- ❌ **Bad:** New chorus depth → `morphFactor` (already used by bass)
- ✅ **Good:** New chorus depth → `chromaticAberration` (unused)

### Rule 2: Hierarchical Consistency
**System Type → Geometry → Parameters**

```
System Type (Tesseract)
  ├─ Oscillator Type: Sine
  ├─ Base Dimension: 4.0D
  └─ Geometry Mode (Hypercube)
      ├─ Filter Type: Low-pass
      ├─ Grid Density: 8.0
      └─ Parameters
          ├─ Cutoff → lineThickness
          ├─ Resonance → glitchIntensity
          └─ Envelope → morphFactor
```

**New additions must fit logically:**
- New **System Type** → New oscillator + dimension range
- New **Geometry Mode** → New filter + grid pattern
- New **Parameter** → New visual mapping within existing hierarchy

### Rule 3: Frequency Band Allocation
**7-Band analyzer mapping must remain exclusive:**

| Band | Reserved For | Do Not Use For |
|------|--------------|----------------|
| 0-1 | Fundamental structure (rotation, density) | Superficial effects |
| 2-3 | Primary movement (XY rotation) | Static parameters |
| 4-5 | Detail/complexity (ZW rotation, thickness) | Global changes |
| 6 | High-frequency detail (dimension, sparkle) | Low-frequency effects |

### Rule 4: Visual Parameter Budget
**Current Visual Parameters: 12 used, 8 available**

| Category | Used | Available | Reserved For |
|----------|------|-----------|--------------|
| **Rotation** | 5 | 3 | Additional 4D planes (YW, XZ, etc.) |
| **Geometry** | 3 | 2 | Advanced morphing, topology shifts |
| **Appearance** | 3 | 2 | Shader effects, material properties |
| **Color** | 1 | 1 | Advanced color systems |

**Before adding new visual parameters, exhaust temporal modulation of existing ones.**

### Rule 5: Visual Parity Balance
**For every audio feature, ask:**
1. What is the sonic essence? (warm, sharp, chaotic, etc.)
2. What visual quality matches? (smooth, angular, fractal, etc.)
3. Does this create new information or duplicate existing?

**Example Decision Tree:**
```
New Effect: Chorus
├─ Sonic Essence: Pitch detuning, width, shimmer
├─ Visual Match: RGB separation, width spreading
├─ Existing Overlap? No (glitch is different)
└─ Conclusion: Add chromaticAberration parameter ✅
```
